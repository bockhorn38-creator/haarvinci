Die einzelne APK in diesem Zweig wurde unverändert aus dem erfolgreichen Android-Emulatortest 42832780923 übernommen. SHA256SUMS.txt und SIGNATUR.txt dokumentieren die geprüfte Originaldatei.

Dokumentation im Hauptzweig: docs/BEHANDLUNGEN-ZAHLUNGEN.md, docs/CHATGPT-IMPORT.md und docs/PRUEFUNG.md. Sieben native Prüfungen einschließlich Kunden-/Kalender-/Sicherungsablauf, Calendar Provider, Android-Textimport sowie Behandlungen/Zahlungen/Import v2 und Prozessneustart sind im Pixel-6-Emulator unter Android 15 geprüft. Testsignierung: die vorherige Testversion bei abweichender Signatur deinstallieren und diese APK frisch installieren. Bisherige lokale Testdaten gehen dabei verloren. Ausschließlich fiktive Daten verwenden. Keine automatische Gerätesynchronisierung.

Der separate Download-Zweig dient als Ersatz, weil die GitHub-Actions-Integration das Anlegen eines GitHub Releases mit HTTP 403 verweigert. Der Hauptzweig enthält ausschließlich Quellcode; die Repository-Sichtbarkeit wird nicht geändert.
