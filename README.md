# Haarvinci Android-Testversion 0.4.0

Die einzelne APK in diesem Zweig wurde unverändert aus dem erfolgreichen Android-Emulatortest 40562980839 übernommen. SHA256SUMS.txt und SIGNATUR.txt dokumentieren die geprüfte Originaldatei.

Neu: Haarprofile, kundenbezogene Extensions mit Anlegen/Bearbeiten/Löschen, chronologische Historie, Suche und Lieferstatus. Das bisherige Design bleibt erhalten.

Testsignierung: die vorherige 0.3.0 gegebenenfalls deinstallieren und diese APK frisch installieren. Bisherige lokale Testdaten gehen dabei verloren. Ausschließlich fiktive Daten verwenden. Keine automatische Gerätesynchronisierung.

Der separate Download-Zweig dient als Ersatz, weil die GitHub-Actions-Integration das Anlegen eines GitHub Releases mit HTTP 403 verweigert. Der Hauptzweig enthält ausschließlich Quellcode; die Repository-Sichtbarkeit wird nicht geändert.
